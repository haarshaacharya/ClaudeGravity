# Multi-AI Studio (local version)

Tumhare computer par chalta hai. AI files likh sakta hai aur terminal commands bhi chala sakta hai.

1. Node.js 18+ install karo.
2. .env.example ka naam .env karo aur keys daalo.
3. start.bat par double-click karo (ya terminal me: node server.js). Browser me http://localhost:3000 khulega.
4. "Open Folder" se apna project chuno. Ya: node server.js "C:\path\to\project"

Ye version Vercel par deploy mat karna. Ye sirf localhost par chalne ke liye bana hai.
